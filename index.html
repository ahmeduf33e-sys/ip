حماية بنمط الآلة الحاسوبية (VM) المستخدمة في ليراف — متعددة الطبقات ويصعب فكّها

🧠

تشفير بنمط VM

الكود يتحول إلى آلة حاسوبية مشفرة متعددة الطبقات مع ربط بالأرتفاكت (Artifact) ليمنع التلاعب بالنسخ القديمة.

🚫

ترخيص Fail-closed

إذا فشل التحقق لأي سبب كان — السكربت يتوقف تماماً ولا يفتح (مغلق افتراضياً عند أي خطأ).

🎮

توافق ESX/QBCore

متوافق مع الأطر الأكثر شيوعاً في فايف ام، يشتغل مع سكرباتك الحالية بدون تعديل.

💻

ربط بـ HWID

تثبيت الترخيص على جهاز العميل يمنع سرقة الملف أو مشاركته مع آخرين.

📡

مراقبة مباشرة

سجلات تحقق لحظية وتنبيهات فورية على الديسكورد لكل محاولة دخول.

🏷️

منصة موثقة بالإصدارات

توثيق API


اربط سكربتك بمنصة Ahmed Dev عبر الواجهات التالية. كل الردود بصيغة JSON.






📘 الواجهات المتاحة


GET /api/reviewsتقييمات المتجر المنشورة (عام)


GET /api/packagesالباقات المتاحة للشراء


GET /api/meمعلومات حسابك الجارية وااشتراكاتك (يتطلب جلسة)


POST /api/orderإرسال طلب شراء باكة عبر الديسكورد


POST /api/redeemتفعيل كود (IP-XXXXX-XXXXX)


POST /api/encryptتشفير ملف وقفله على IP (يتطلب اشتراك نشط)


GET /api/my-ordersسجل طلباتك


POST /api/reviewsإضافة/تحديث تقييم (بعد الشراء)
